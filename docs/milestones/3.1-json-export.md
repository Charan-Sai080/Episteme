# Milestone 3.1: JSON Graph Export

## Goal
Export the internal SQLite graph (or subgraphs) into a standardized JSON format (Node-Link structure) that can be easily consumed by external visualization tools (like D3.js, Cytoscape, or our future Web UI).

## Architecture Rules
* Use Jackson for JSON serialization.
* The output format should strictly separate `nodes` and `edges` arrays to align with standard graphing libraries.

## Granular Sub-Milestones

### [x] 3.1.1: Export DTO Scaffolding
- Define `ExportNodeDTO` (id, label, type) and `ExportEdgeDTO` (source, target, type).
- Define the root `GraphExportDTO` containing lists of nodes and edges.

### [x] 3.1.2: Graph Export Service
- Create `GraphExportService.java`.
- Implement a method to extract the entire graph (or a limited subset) from SQLite into a `GraphExportDTO`.
- Ensure performance (e.g., batch loading nodes and edges).

### [x] 3.1.3: CLI Export Command
- Create `ExportCommand.java` in the CLI package.
- Wire it to Picocli to allow users to run `episteme export -d <project> -o output.json`.
- Run tests to ensure JSON is properly serialized to disk.
